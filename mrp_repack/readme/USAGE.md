In *Inventory > Reporting > Stock by Location* (or any list of stock), select the stock to repack and use the *Repack* action. A confirmed repacking order is created for each line, with its lot to be produced again.

Start the operation of the order when repacking starts and finish it at the end, set the quantity produced (or capture it by weighing with `mrp_capture`) and mark the order as done.

A repacking order can also be created by hand with a repacking operation type: the product is added as component when it is confirmed.
