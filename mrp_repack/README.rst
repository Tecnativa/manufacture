This module repacks a product with manufacturing orders that consume the
product they produce, so the time spent repacking adds to its cost. It
is meant for products weighed and packed again, e.g. bulk product put in
packages of variable weight, without creating a second product for the
packed one.

A bill of materials cannot have its product as component, so repacking
orders have no bill of materials: they get the product as component and
an operation in the repacking work center when they are confirmed. The
operation time is valued at the cost per hour of the work center and
added to the value of the repacked product. The lot of the order is
consumed and produced again, so repacking keeps the lot.

Odoo computes the average cost replaying the moves in order, and the
moves of a manufacturing order are done at the same time, so this module
makes sure the consumption is valued before the production. Otherwise
the cost of the operation would be spread over the stock both before and
after repacking.

Configuration
=============

Create a manufacturing operation type for repacking and, in its
*Repacking* section:

- Tick *Repacking*.
- Choose the *Repacking Work Center*, whose cost per hour values the
  time spent repacking.

Usage
=====

In *Inventory > Reporting > Stock by Location* (or any list of stock),
select the stock to repack and use the *Repack* action. A confirmed
repacking order is created for each line, with its lot to be produced
again.

Start the operation of the order when repacking starts and finish it at
the end, set the quantity produced (or capture it by weighing with
``mrp_capture``) and mark the order as done.

A repacking order can also be created by hand with a repacking operation
type: the product is added as component when it is confirmed.
